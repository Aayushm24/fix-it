# pr-team-pushback

**Paste this into Claude:** create a new Project, open "Set project instructions", paste
`project-instructions.md` (everything below the line), then ask: "Review this pitch: [paste]".

What it does: makes Claude argue with your briefs, pitches and coverage reports before a
client or journalist sees them, with the line, the reason and a rewrite.

Test it: paste a pitch you know is weak. If Claude opens with praise, the instructions didn't save.

Tested: dry run, Nov 22 2026, opened "Not ready" with 3 line-level fixes on a weak sample pitch; fixed a cap-vs-workflow conflict and the forced UK English. Not yet verified on a real setup.
