# fix-it

Small, free fixes for Claude Code, agent and automation setups.

- `ai-build-preflight`: checks an AI build guide for gaps in permissions, stale data and handoffs before anyone builds it.
- `automation-runbook`: a skill that writes a one-page runbook and fix table for any Zapier, Make or n8n workflow.
- `claude-code-session-1`: a hands-on Claude Code session where trainees fix a seeded bug, test first.
- `pr-team-pushback`: project instructions that make Claude challenge briefs, pitches and reports instead of agreeing.
- `smb-claude-rollout`: a per-client data rules sheet, admin settings checklist and a 1-hour staff session for rolling out Claude.
- `source-check-ops`: checks each Claude-drafted piece against its source and flags only the misses.
- `workflow-to-agent-map`: maps a repeated human workflow into an agent, with steps, sign-offs, failure points and a KPI.
