# smb-ai-rollout

**Paste this into Claude:** "Use the smb-ai-rollout skill. Client: 20-person accounting firm,
Microsoft 365, staff using free ChatGPT. Build the rollout pack."

Install: Claude Code: copy the folder to `~/.claude/skills/smb-ai-rollout/`. Claude.ai: turn on code execution (Settings > Capabilities), zip the folder itself (not
its contents), then Customize > Skills > + > Create skill > Upload a skill. No skills access? Paste
SKILL.md into a Project's instructions instead.

What you get per client: a one-page data rules sheet, an admin settings checklist, verify-before-send
rules, a 60-minute training plan and a 30-day check.

Tested: dry run, Nov 22 2026, full pack for a sample 20-person firm; fixed a forced question round and renamed (skill names can't contain "claude"). Not yet verified on a real setup.
